E-commerce Sales & Profit Analysis

📌 Problem
Businesses often struggle to understand which products and strategies drive profitability.

📌 Objective
To analyze sales and profit data to identify key drivers of revenue and uncover loss-making areas.

📌 Tools Used
Excel (Pivot Tables, Dashboard)
Python (Pandas, Matplotlib)
SQL-style analytical thinking

📌 Approach
Cleaned and prepared raw sales data
Performed exploratory data analysis using Excel and Python
Built an interactive dashboard to visualize trends
Identified key business insights

📌 Key Insights
West region generates the highest sales
Furniture category shows high sales but low profitability
Discounts negatively impact profit margins
A small number of products contribute significantly to revenue

📌 Business Recommendations
Reduce discounts on low-margin products
Focus on high-profit categories
Optimize product portfolio
Target high-performing regions

📌 Outcome
This project demonstrates how data analysis can drive business decisions by identifying key trends and improving profitability.
